## 🇧🇷 Sobre o Projeto (Portuguese)

O **Bazar Vitrine & Dashboard** foi desenvolvido para digitalizar e simplificar a operação de bazares. Conta com uma interface focada em **PWA** (Ionic) para os clientes navegarem na vitrine pelo celular, integrada a um ecossistema robusto em Laravel e Node.js para controle total de estoque, reservas temporárias e relatórios de métricas.

### ✨ Principais Funcionalidades
* **Vitrine PWA:** Catálogo dinâmico de itens com busca e filtros por categoria.
* **Sistema de Reservas:** Bloqueio temporário do item integrado ao fluxo de pagamento do **Mercado Pago**.
* **Painel de Métricas & Admin (CRUD):** Ferramentas para adicionar, editar, remover itens e acompanhar o faturamento e vendas em tempo real.

---

## 🇬🇧 About the Project (English)

The **Bazar Vitrine & Dashboard** was built to digitalize and streamline bazaar operations. It features a mobile-first **PWA** interface (Ionic) for customers to browse the storefront, backed by a robust Laravel and Node.js ecosystem for total inventory control, temporary item reservations, and metrics reporting.

### ✨ Main Features
* **PWA Storefront:** Dynamic item catalog with search and category filters.
* **Reservation System:** Temporary product hold integrated with **Mercado Pago** checkout flow.
* **Metrics & Admin Dashboard (CRUD):** Tools to add, edit, and remove items, while tracking revenue and sales in real time.

---

## 🛠️ Tecnologias / Tech Stack

* **Frontend:** Ionic (PWA)
* **Backend / API:** PHP (Laravel) & Node.js
* **Pagamentos / Payments:** Mercado Pago API
